## شواهد برنامهٔ ۱٫۷

- [x] [گزارش آزمون جاری](../review-evidence/ux-release.json): ۴۰ بررسی API، ۵ تقویم، ۱۰ رابط، ۶ گردش نقش‌ها، ۶ مسیرهای خطا، ۱۳ نمایش و ۳ شروع برنامه؛ مجموع ۸۳ با احتساب پنج والد، ۷۸ بررسی مستقل.
- [x] TypeScript، lint، build سرور و نمایش، آزمون محلی D1/R2 و مرورگر همان build موفق‌اند؛ تاریخ اجرا در گزارش حفظ شده است.
- [x] عضو: ورود، رضایت، پاسخ، ذخیره/تعارض، مدارک، پرداخت نمایشی، ارسال و ماندگاری بررسی شده‌اند.

- [x] کارشناس: ارجاع با رضایت، هماهنگی، تأیید مرکز/زمان/مرجع و انعکاس انجام اقدام بررسی شده‌اند.
- [x] مدیر: دعوت/ظرفیت، تعلیق/تخصیص و پاسخ پشتیبانی بررسی شده‌اند؛ پاسخ معمول به معنی اجرای حذف/بازپرداخت نیست.
- [x] [انتشار عمومی](../review-evidence/ux-publication.json): شش فایل کلیدی از HTTPS با build تطبیق دارند. push مخزن به‌تنهایی شاهد انتشار نیست.
- [x] [گزارش جریان‌ها و حدود آزمون](FLOW-REVIEW-v1.7-fa.md) موجود است؛ آزمون‌ها تضمین نبود هر نوع باگ نیستند.

## هماهنگی بستهٔ اسناد ۱٫۷٫۱

این دور به فایل‌های برنامه دست نمی‌زند. `scripts/validate_complete_delivery.py` سلامت ZIP، هش همهٔ فایل‌ها، تطابق سورس/build، لینک‌های HTML و Markdown و نسخه‌ها را بررسی می‌کند؛ خروجی آن پس از ساخت در `review-evidence/ux-archive-validation.json` ثبت می‌شود. راهنمای HTML و PDF از اسناد جاری ساخته می‌شوند؛ راهنمای تحویل قدیمی بازاستفاده نمی‌شود.
