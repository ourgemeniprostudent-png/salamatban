# سلامت‌بان — چک‌لیست تحویل و انتشار

تاریخ: ۱۴ مهر ۱۴۰۵ / ۶ اکتبر ۲۰۲۶

این فهرست وضعیت بازبینی پایه را از آزمون نسخه تازه و راه‌اندازی واقعی جدا می‌کند. موارد آزمون تازه تنها پس از ثبت نتیجه واقعی علامت زده شوند. نتیجهٔ آزمون تازه در `review-evidence/identity-release.json` ثبت شده است. تأیید انتشار عمومی جداگانه پیگیری می‌شود.

## شواهد بررسی‌شده

- [x] ZIP تازه با مخزن مقایسه شد: ۱۶ سند و ۵۶ فایل رابط، برابر با بخش مرجع قبلی‌اند. بسته دریافتی **مرجع تکمیل تجربه** است؛ برتری یا آمادگی عملیاتی آن از نام «complete» نتیجه نمی‌شود.
- [x] مسیر اجرایی فعلی `site/app/pilot/` و `site/lib/pilot/` شناسایی شد؛ کد `reference-code/` در build فعال اجرا نمی‌شود.
- [x] ۹ وزن Peyda ارسالی کاربر در `site/public/fonts/PeydaWebFaNum-*.woff2` موجود است.
- [x] گزارش پایه `deliverables/readiness.json`، ۳۴ آزمون موفق تحویل قبلی با ارائه‌دهندگان شبیه‌سازی‌شده را ثبت کرده است؛ این گزارش شاهد آزمون تغییرات جدید نیست.
- [x] وضعیت سرویس‌ها از کد بررسی شد: پرداخت/SMS دارای واسط‌اند؛ کلیدها و تأیید تولیدی حاضر نیست؛ دکترتو و CRM متصل نشده‌اند.

## تحویل هویت و تجربه تازه

- [x] نام سلامت‌بان، نشان و favicon، عنوان صفحه و متادیتا در خروجی ساخته‌شده یکسان‌اند.
- [x] راهنمای هویت شامل لوگو، نسخه تک‌رنگ/معکوس، رنگ و کنتراست، تایپوگرافی Peyda، قواعد فاصله و نمونه اجزاست.
- [x] خانه سلامت، تصویر سلامت، مدارک، نوبت‌ها، حساب/حریم خصوصی و برنامه پیگیری زمان‌بندی‌شده از ناوبری قابل دسترسی‌اند.
- [x] پیشرفت و وضعیت‌ها از پرونده جاری محاسبه می‌شوند؛ عدد سلامتی یا آمار پزشکی بی‌منبع ساخته نشده است.
- [x] صف پزشک قابل جست‌وجو/فیلتر است؛ میز هماهنگی و مدیریت نقش و عمل مشخص دارند.
- [x] حالت خالی، خطا، بارگذاری، تغییر ذخیره‌نشده و موفقیت برای عملیات اصلی روشن است.
- [x] فونت‌ها محلی بارگیری می‌شوند و فایل‌های نمایشی به ریشه دامنه وابسته نیستند.

## آزمون رفتاری تحویل تازه

- [x] `npm test` پس از آخرین تغییرات موفق است؛ گزارش تازه جدا از گزارش پایه حفظ شده است.
- [x] `npm run lint`، `npx tsc --noEmit` و `npm run build` موفق‌اند.
- [x] `npm run build:demo` و `npm run test:demo` روی بسته تازه موفق‌اند.
- [x] مسیر عضو: ورود ← رضایت/فرم ← فایل ← پرداخت آزمایشی ← ارسال، کامل طی شده است.
- [x] مسیر پزشک: پرونده تخصیص‌یافته ← درخواست تکمیل یا انتشار ← نمایش نتیجه برای عضو، کامل طی شده است.
- [x] ثبت/بازگشایی اقدام و مشاهده آن پس از Refresh، نسخه اصلی برنامه را تغییر نمی‌دهد.
- [x] درخواست نوبت ← هماهنگی کارشناس ← تأیید با مرکز/زمان/مرجع/رضایت برای عضو قابل مشاهده است.
- [x] پزشک دیگر، عضو دیگر، کارشناس و مدیر دسترسی ناخواسته به مدارک بالینی ندارند.
- [x] کارکرد نمایشی در زیرمسیر، عرض ۳۲۰ پیکسل و دسکتاپ بررسی شده؛ خطای مرورگر و پیمایش افقی ناخواسته ندارد.
- [ ] آدرس انتشار نهایی باز شده و محتوای همین نسخه را نشان می‌دهد؛ Push به‌تنهایی شاهد انتشار سایت نیست.
- [x] نسخه تحویل، SHA کامیت، تاریخ ساخت، نام ZIP و فهرست آزمون‌ها ثبت شده‌اند.
