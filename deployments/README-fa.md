# انتشار نسخهٔ نمایشی سلامت‌بان

این بسته برای نمایش به کارفرما روی هاست اشتراکی آماده شده است. ظاهر و منطق پایلوت از برنامهٔ اصلی استفاده می‌شوند؛ SQL و فایل‌های ساختگی در مرورگر با SQLite/WASM و IndexedDB نگهداری می‌شوند. هیچ API یا حساب Cloudflare، دیتابیس هاست، Node.js روی هاست یا کلید پرداخت لازم نیست.

## بارگذاری در DirectAdmin / AXFile

1. در File Manager دامنهٔ `temporarydomain.ir` وارد `public_html` شوید.
2. پوشهٔ `salamatban-demo` را بسازید و وارد آن شوید. مسیر نهایی باید `/domains/temporarydomain.ir/public_html/salamatban-demo/` باشد.
3. فایل `salamatban-demo.zip` کنار این راهنما را با **Upload Files** در همین پوشه آپلود کنید.
4. روی ZIP گزینهٔ **Extract** را بزنید و مقصد را همین پوشه انتخاب کنید. ZIP پوشهٔ اضافه‌ای ندارد: `index.html` باید مستقیماً در `salamatban-demo` قرار بگیرد.
5. بعد از Extract، ZIP را از هاست حذف کنید. `index.php` و فایل‌های سایت اصلی در `public_html` را تغییر ندهید.
6. آدرس `https://temporarydomain.ir/salamatban-demo/` را باز کنید. نمایش نیازمند HTTPS و مرورگر به‌روز است. اگر دامنه گواهی معتبر ندارد، ابتدا SSL همان دامنه را از پنل فعال کنید.

فایل `.htaccess` برای نوع WASM و جلوگیری از کش‌شدن نسخه‌های قدیمی در بسته است؛ نمایش فایل‌های مخفی را فعال کنید تا وجودش مشخص باشد. بسته شامل سورس، کلید یا تنظیمات محیط واقعی نیست.

## بررسی با کارفرما

- در صفحهٔ ورود «حساب‌های ساختگی برای بررسی نقش‌ها» را باز کنید و یک نقش انتخاب کنید.
- پس از درخواست کد، کد ساختگی همان آزمون روی صفحه نمایش داده می‌شود؛ پیامک واقعی ارسال نمی‌شود.
- با نقش کاربر، رضایت و پرونده را تکمیل، پرداخت نمایشی را انجام و پرونده را ارسال کنید.
- خروج کنید و در **همان مرورگر** با نقش پزشک وارد شوید؛ همان پرونده در صف دیده می‌شود و می‌توان برایش برنامه منتشر کرد.
- نقش کارشناس هماهنگی و مدیر نیز قابل بررسی‌اند. اطلاعات مرورگر افراد مختلف با هم مشترک نیست.
- «شروع دوبارهٔ نمایش» فقط اطلاعات این نسخه در همین مرورگر را پاک می‌کند. دادهٔ واقعی پزشکی یا بانکی وارد نشود.

## نسخه‌های بعدی

فایل جدید را در همین پوشه آپلود و Extract کنید تا لینک ثابت بماند. اطلاعات نمایشی داخل مرورگر باقی می‌مانند؛ برای سناریوی تازه از دکمهٔ شروع دوباره استفاده کنید. برای نگه‌داشتن یک نسخهٔ مستقل، بسته را در پوشهٔ دیگری مثل `salamatban-demo-v2` Extract کنید؛ مسیرهای فایل‌ها نسبی‌اند و نیازی به تغییر تنظیمات نیست.

## ساخت و تست

در پوشهٔ `site` با Node.js 24 و Python 3:

```sh
npm ci
npm run build:demo
npm run test:demo
npm run package:demo
```

آزمون مرورگر به Chromium نیاز دارد؛ پیش‌فرض `/usr/bin/chromium` است و می‌توان `CHROMIUM_PATH` را تنظیم کرد. تست‌ها نصب دامنه و SSL یا موفقیت آپلود به هاست را اثبات نمی‌کنند؛ آدرس عمومی باید بعد از آپلود بررسی شود.

## دستور انتقال برای جلسهٔ محلی دارای ابزار مرورگر

> فایل `deployments/salamatban-demo.zip` را از مخزن `ourgemeniprostudent-png/salamatban` دریافت کن. با ابزار کنترل مرورگر و نشست فعلی من، در پنل `https://server130s.irwebspace.com:2223/CMD_PLUGINS/axfilepro/index.raw` به `/domains/temporarydomain.ir/public_html/salamatban-demo/` برو. اگر پوشه وجود ندارد آن را بساز؛ اگر فایل‌های قبلی دارد، قبل از جایگزینی آن‌ها را حفظ کن. ZIP را آپلود و در همان پوشه Extract کن. به فایل‌های سایت اصلی دست نزن. سپس صفحهٔ عمومی `https://temporarydomain.ir/salamatban-demo/`، ورود ساختگی و ذخیره/بازخوانی را بررسی کن. این درخواست شامل آپلود و Extract است؛ رمز یا نشست را در گفتگو یا فایل‌های پروژه ننویس.
