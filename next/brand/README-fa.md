# بسته هویت بصری سلامت‌بان

نام ثابت برند: **سلامت‌بان** / **Salamatban**

فایل `brand/index.html` را برای دیدن راهنمای کامل باز کنید. پوشه‌های `brand` و `fonts` باید کنار هم بمانند تا نمونه‌های قلم به‌درستی نمایش داده شوند.

- `brand/logo.svg`: نشان رنگی اصلی؛ واژه‌نشان به مسیر برداری تبدیل شده است.
- `brand/logo-mono.svg`: نشان تک‌رنگ برای زمینه روشن.
- `brand/logo-reverse.svg`: نشان معکوس برای زمینه تیره.
- `brand/symbol.svg`: نماد مستقل و آیکن سایت.
- `brand/tokens.json`: رنگ، تایپوگرافی، فاصله، شعاع گوشه و قواعد کاربرد.
- `brand/fonts.json`: مشخصات، وزن و هش فایل‌های اصلی قلم ارسالی پروژه.
- `fonts/`: هر ۹ وزن اصلی PeydaWebFaNum، بدون تغییر در فایل‌های فونت.
- `og.png`: تصویر اشتراک‌گذاری تازه، با اندازه ۱۲۰۰ × ۶۳۰ پیکسل.
- `brand/social-card.html`: منبع HTML تصویر اشتراک‌گذاری؛ کاملاً مبتنی بر قلم و نشان همین بسته.
- `Salamatban-Visual-Identity.pdf`: نسخه PDF راهنمای هویت بصری.

## کاربرد هویت سلامت‌بان

نشان، واژه‌نشان پیدا و پالت آبی و فیروزه‌ای یک هویت مستقل و یکپارچه برای سلامت‌بان می‌سازند. این راهنما مرجع رنگ، تایپوگرافی، فاصله‌گذاری و لحن برند در نرم‌افزار، ارائه‌ها و مستندات است.

| نقش رنگ در سلامت‌بان | مقدار |
| --- | --- |
| آبی هویت `accent` | `#4187FF` |
| اقدام اصلی `primary` | `#346ED1` |
| حالت اشاره‌گر `primaryHover` | `#2755A3` |
| آبی عمیق `primaryDeep` | `#1A3B74` |
| زمینه آبی `primarySoft` | `#ECF3FF` |
| حاشیه آبی `primaryBorder` | `#C6DBFF` |
| فیروزه‌ای مکمل `cyan` | `#45CAF6` |
| متن ثانویه `muted` | `#667085` |

مقادیر `tokens.json` مرجع پیاده‌سازی‌اند. سفید روی `#346ED1` نسبت کنتراست **۴٫۸۹:۱** و روی `#2755A3` نسبت **۷٫۲۱:۱** دارد. سفید روی `#4187FF` نسبت **۳٫۴۲:۱** دارد؛ این رنگ برای نوشته کوچک سفیدِ دکمه استفاده نمی‌شود.

برای متن‌های کوچک از سبزآبی تیره `#087F76` استفاده کنید. سبزآبی روشن `#14A89B` برای نشانگر پیشرفت و وضعیت مثبت است؛ فیروزه‌ای `#45CAF6` نقش مکمل برند را دارد. نام برند، نسبت نشان و فضای خالی آن مطابق راهنما حفظ شود.
