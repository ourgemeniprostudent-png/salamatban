# گزارش بررسی جریان‌های سلامت‌بان — نسخهٔ ۱٫۷

تاریخ: ۱۴ مهر ۱۴۰۵ / ۶ اکتبر ۲۰۲۶

این گزارش دامنهٔ بررسی و نتیجهٔ قابل بازتولید را بیان می‌کند. همهٔ داده‌های آزمون ساختگی‌اند. موفقیت آزمون‌ها تضمین نبود هر نوع باگ یا آمادگی خدمت پزشکی واقعی نیست.

## ایرادهای یافته‌شده و اصلاح‌شده

| مسئله | اصلاح و رفتار نهایی |
|---|---|
| توقف پرداخت فقط با عبارت مبهم «تا بررسی پزشک» | توضیح علت پاسخ «بله» فعلی/قبلی، حفظ پاسخ‌ها، مسئول بررسی و راهنمای نقش نمونه؛ علت توقف و لینک راهنما کنار دکمهٔ غیرفعال |
| تغییر پاسخ به «خیر» ولی ادامهٔ توقف بدون توضیح | توضیح صریح پابرجاماندن هشدار ثبت‌شده؛ پرونده بدون پرداخت در صف پزشک دیده می‌شود |
| علامت تازه پس از بررسی قبلی پزشک | پاسخ هشدار تازه، تأیید قبلی را بازنشانی می‌کند؛ ذخیرهٔ بدون تغییر، هشدار بررسی‌شده را دوباره باز نمی‌کند |
| پایان بررسی پزشک و بستن وظیفهٔ هشدار جدا از هم | تغییر پرونده و وظیفه در تراکنش و با کنترل نسخه؛ نتیجه و قدم بعدی به پزشک گفته می‌شود |
| بارگذاری مدرک شمارهٔ نسخه را در فرم جلو نمی‌برد | نسخهٔ فرم پس از بارگذاری به‌روز می‌شود، بدون جایگزینی ویرایش‌های محلی؛ بارگذاری چند مدرک و ادامهٔ ذخیره/پرداخت/ارسال آزموده شد |
| بازگشایی پرونده با وجود برنامهٔ قدیمی | خانه، تکمیل اطلاعات یا انتظار بررسی تازه را مقدم نشان می‌دهد؛ برنامهٔ قبلی برچسب روشن دارد و محفوظ است |
| پایان نشست هنگام ویرایش | ورود دوباره به همان حساب در همان صفحه، بدون پاک‌کردن پاسخ‌ها؛ ذخیرهٔ خودکار تا احراز مجدد متوقف می‌شود |
| چند ذخیرهٔ هم‌زمان در انتظار یک درخواست | صف ذخیره تا پایان درخواست جاری منتظر می‌ماند و شمارهٔ نسخه را حفظ می‌کند |
| خطاهای خام/نامفهوم برای نقش‌ها | پیام‌های مشترک دارای علت و اقدام بعدی؛ سؤال الزامیِ جاافتاده با نام سؤال و زمان باقی‌ماندهٔ محدودیت تلاش با مدت مشخص |
| سفارش ناموجود یا تغییر رسید پرداخت موفق | شناسه/مالک/وضعیت بررسی می‌شود؛ تکرار همان نتیجه امن است و رسید پرداخت‌شده با نتیجهٔ متناقض عوض نمی‌شود |
| دعوت تکراری یا پاسخ به درخواست ناموجود | خطای مشخص عضو تکراری و مورد پیدا نشده؛ موفقیت کاذب برگردانده نمی‌شود |
| پاسخ پشتیبانی به‌جای اجرای حذف/بازپرداخت | بستن با پاسخ معمول فقط برای مشکل/پیشنهاد مجاز است؛ درخواست اجرای واقعی باز می‌ماند |
| ارجاع هم‌زمان با انتشار نسخهٔ تازه | ایجاد کار فقط برای آخرین برنامه و وضعیت منتشرشده انجام می‌شود |

## ماتریس بررسی

| جریان | بررسی خودکار |
|---|---|
| ورود | شماره و کد، مصرف یک‌باره، محدودیت تلاش، ورود حساب‌های نقش‌ها، انقضای نشست و ورود مجدد با حفظ ویرایش |
| فرم | رضایت صریح، سؤال الزامی، بله/خیر بدون پیش‌انتخاب، چندانتخابی انحصار «هیچ‌کدام»، اختیاری‌ها، عقب/جلو و ویرایش مرور |
| ذخیره | ذخیره خودکار، قطع ذخیره، تلاش مجدد، ویرایش حین ذخیره، تعارض نسخه و تأیید بازخوانی |
| هشدار | پاسخ قبلی اصلاح‌شده، توضیح توقف پرداخت، صف پزشک قبل از پرداخت، یادداشت کوتاه نامعتبر، رفع توسط پزشک و هشدار تازه پس از رفع |
| مدارک | چند فایل، اعتبارسنجی نوع واقعی فایل، فایل تکراری، پیش‌نمایش، شکست و تلاش مجدد، مالکیت دریافت، ویرایش و ارسال بعد از بارگذاری |
| پرداخت | مقدار سمت سرویس، سفارش یکتا، انتظار، شکست، انصراف، ادامه بعد از بازکردن صفحه، رسید ماندگار، خطای ذخیره و تلاش مجدد، جلوگیری از نتیجه متناقض |
| پزشک | تخصیص و دسترسی، درخواست تکمیل، ارسال دوباره بدون پرداخت مجدد، انتشار برنامه، بازگشایی، حفظ نسخه قبلی و ارجاع تیم |
| کارشناس | صف ارجاع/درخواست، رضایت، جلوگیری از پرش وضعیت، مرکز/زمان/کد، تکمیل مرتبط با اقدام برنامه و لغو |
| مدیر | دعوت تکراری، ظرفیت و تخصیص پزشک، تعلیق و لغو دسترسی، پاسخ و پایان رسیدگی مشکلات معمول، بازماندن درخواست حذف/بازپرداخت |
| نقشه | نمایش با انتخاب کاربر، جست‌وجوی صریح، رد مجوز، قطع ارائه‌دهنده، لغو و آدرس دستی؛ پاسخ سرویس نقشه در آزمون کنترل‌شده است |
| بارگذاری | دریافت موازی WASM، انتظار طولانی، تلاش مجدد و توقف بارگذاری مسدود؛ ذخیرهٔ قدیمی بدون حذف به‌روز می‌شود |
| نمایش | RTL، عرض‌های ۳۲۰، ۳۶۰، ۳۹۰ و ۱۴۴۰ پیکسل در Chromium؛ راهنمای هشدار در موبایل بازبینی شد |

فرمان‌ها در پوشه `site/`: `npm test`، `npm run test:calendar`، `npm run test:ux`، `npm run test:workflow`، `npm run test:edges`، `npm run test:demo`، `npm run test:startup`، `npm run lint`، `node node_modules/typescript/bin/tsc --noEmit`، `npm run build` و `npm run build:demo`.

نتایج شمارش و زمان اجرا در `review-evidence/ux-release.json`، `api-tests.json`، `ux-tests.json`، `workflow-tests.json` و `edge-tests.json` آمده‌اند. شمارش Node شامل آزمون والد است؛ آن‌ها آزمون مستقل اضافی محسوب نشده‌اند. انتشار عمومی با پاسخ HTTPS و تطبیق هش فایل‌ها از push سورس جدا بررسی می‌شود.

## محدودیت بررسی

- مرورگر خودکار Chromium است؛ Safari/Firefox و دستگاه فیزیکی Android/iPhone، دوربین و GPS واقعی در این دور بررسی نشده‌اند.
- پرداخت بانکی، پیامک واقعی، اتصال مرکز، حذف عملیاتی اطلاعات و بازپرداخت واقعی فعال نیستند. رفتار واسط پرداخت با پاسخ ساختگی آزموده شده است.
- GitHub Pages داده را در همین مرورگر نگه می‌دارد؛ کاربر و پزشک روی دو دستگاه پایگاه مشترک ندارند.
- آزمون مستقیم Chromium روی دامنه عمومی به اعتماد گواهی پراکسی محیط محدود است. هیچ کنترل TLS غیرفعال نشده؛ فایل‌های عمومی تطبیق داده می‌شوند و رفتار همان build در مرورگر محلی بررسی می‌شود.
- آزمون با کاربران واقعی، تأیید بالینی، بار عملیاتی و بررسی جامع امنیتی مستقل انجام نشده است. دامنهٔ این کار، صحت گردش‌های موجود و روشن‌بودن اقدام بعدی است.
