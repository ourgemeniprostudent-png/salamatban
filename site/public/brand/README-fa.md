# بسته هویت بصری سلامت‌بان

نام ثابت برند: **سلامت‌بان** / **Salamatban**

فایل `brand/index.html` را برای دیدن راهنمای کامل باز کنید. پوشه‌های `brand` و `fonts` باید کنار هم بمانند تا نمونه‌های قلم به‌درستی نمایش داده شوند.

- `brand/logo.svg`: نشان رنگی اصلی؛ واژه‌نشان به مسیر برداری تبدیل شده است.
- `brand/logo-mono.svg`: نشان تک‌رنگ برای زمینه روشن.
- `brand/logo-reverse.svg`: نشان معکوس برای زمینه تیره.
- `brand/symbol.svg`: نماد مستقل و آیکن سایت.
- `brand/tokens.json`: رنگ، تایپوگرافی، فاصله، شعاع گوشه و قواعد کاربرد.
- `brand/fonts.json`: مشخصات، وزن و هش فایل‌های اصلی قلم ارسالی پروژه.
- `fonts/`: هر ۹ وزن اصلی PeydaWebFaNum، بدون تغییر در فایل‌های فونت.
- `og.png`: تصویر اشتراک‌گذاری تازه، با اندازه ۱۲۰۰ × ۶۳۰ پیکسل.
- `brand/social-card.html`: منبع HTML تصویر اشتراک‌گذاری؛ کاملاً مبتنی بر قلم و نشان همین بسته.
- `Salamatban-Visual-Identity.pdf`: نسخه PDF راهنمای هویت بصری.

نشان سلامت‌بان طراحی مستقل دارد. دکترتو شریک معرفی‌شده پروژه است و ظاهر وب‌سایت فعال آن اکنون از منابع عمومی بررسی شده است. این مشاهدهٔ CSS و دارایی‌های سایت، «راهنمای رسمی هویت برند» محسوب نمی‌شود. لوگوی سلامت‌بان بازطراحی یا نسخه‌ای از نشان دکترتو نیست.

قلم وب‌سایت شریک در CSS با نام `iranSans` و وزن متغیر ۱۰۰ تا ۹۰۰ معرفی شده است؛ نام داخلی فایل دریافت‌شده **IRANSansXV** است. سلامت‌بان مطابق انتخاب مالک پروژه از **PeydaWebFaNum** استفاده می‌کند؛ قلم شریک به بسته افزوده نشده است.

شعاع‌های گوشه در CSS شریک: ۴، ۸، ۱۲، ۱۶، ۲۰، ۲۴ و ۳۲ پیکسل. کارت‌ها و کنترل‌های صفحه از الگوی زمینه روشن، حاشیه خاکستری ملایم و آبی فعال استفاده می‌کنند. فایل نشان بررسی‌شده، نوشتار لاتین Doctoreto در کنار نماد پزشکی آبی/فیروزه‌ای است و به بسته سلامت‌بان کپی نشده است.

نکته کاربردی کنتراست: سفید روی `#4187FF` نسبت **۳٫۴۲:۱** دارد و برای نوشته کوچک دکمه مناسب نیست. گونه `#346ED1` نسبت **۴٫۸۹:۱** و `#2755A3` نسبت **۷٫۲۱:۱** دارد؛ در این نسخه، `#346ED1` برای اقدام اصلی، `#2755A3` برای حالت اشاره‌گر و `#1A3B74` برای آبی عمیق اعمال شده است؛ زمینه و حاشیه نیز به‌ترتیب `#ECF3FF` و `#C6DBFF` هستند. دو توکن `partnerAccent` و `partnerCyan` رنگ‌های مشاهده‌شده `#4187FF` و `#45CAF6` را نگه می‌دارند. مقادیر سلامت‌بان در `tokens.json` مرجع پیاده‌سازی‌اند. هم‌راستایی بصری به معنای راهنمای رسمی شریک یا اتصال عملیاتی به API آن نیست.
